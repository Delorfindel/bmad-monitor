# Story 14.1: Audit Accessibility of the Map Legend

Status: backlog
Priority: P1
Size: S

## Story

As an operator using a screen reader,
I want the map legend to be announced correctly,
so that layer state is not conveyed by colour alone.

## Acceptance Criteria

1. **Given** the legend, **when** it is inspected, **then** every layer state has a text label as well as a colour.
2. **Given** keyboard navigation, **when** the legend is traversed, **then** focus is visible on every control.
3. **Given** reduced-motion preferences, **when** layers toggle, **then** no decorative animation runs.

## Tasks / Subtasks

- [ ] 1. Run the audit (AC: 1-3)
- [ ] 2. Record findings with severities
